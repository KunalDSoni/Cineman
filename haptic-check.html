iOS Haptic Capability Check

Tap each test once. Note which ones you physically FEEL. Make sure Settings → Sounds & Haptics → System Haptics is ON and Low Power Mode is OFF.

① Real native switch — drag/tap it

Direct manipulation of a native switch. This is the most reliable iOS web haptic. If even THIS does nothing, your device/settings don’t expose web haptics and no code can change that.

② Trusted tap (label overlay)

Your finger toggles a transparent switch overlaid on the button — the technique used for in-page taps. Should feel a tick on release.

③ Scripted toggle

JavaScript calls .click() on a hidden switch — what The Reel uses for auto/scroll moments. Usually does NOT fire on iOS.

④ navigator.vibrate()

The standard Vibration API. Works on Android; absent on iOS.
